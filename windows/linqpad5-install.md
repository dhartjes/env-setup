# LINQPad 5 Install

<-- [Back to README](../README.md)

LINQPad 5 targets .NET Framework 4.8 and is required for querying legacy .NET 4.x codebases. Install it alongside LINQPad 8 if needed — they run side by side.

```powershell
winget install Linqpad.Linqpad.5
```
