# Clone required git repos

<-- [Back to README](../../README.md)

```bash
cd ~/projects
git clone https://github.com/dhartjes/env-setup.git
git clone https://github.com/dhartjes/ubuntu-config.git
git clone git@github.com:dhartjes/dhartjes.github.io.git
```

After cloning, link your configurations:

```bash
cd ~/projects/ubuntu-config
./setup.sh
```
